## 4. Stack and architecture

- Next.js 16.4 App Router, React 18.3, TypeScript, Tailwind 3.4, framer-motion 10, GSAP, lucide-react, lottie-web (light build). React 19 is blocked by `blobity`.
- Pages are static. The only server route is `POST /api/enquiry` (contact form email). `/contact` reads `?service=` in the browser.
- Content: projects in `content/projects/*.md` (+ images in `public/projects/<slug>/`), blog in `content/blog/*.md`, parsed by an in-house frontmatter parser (`app/lib/frontmatter.ts`, `markdown.tsx`). Services, locations, learn pages, courses and the About journey are TypeScript data files in `app/lib/`.
- Every top-level section has its own `layout.tsx` wrapping `SiteShell` (header, footer, scroll). **A new top-level page without it has no header and cannot scroll.**
- Metadata: use `pageMeta()` from `app/lib/seo.ts` (a page that sets its own openGraph replaces the root one). Share images are generated by `opengraph-image.tsx` files with `generateStaticParams`.
- Colours: CSS variables in `app/globals.css`, Tailwind tokens `bg-primary`, `bg-secondary`, `text-ink`, `text-ink-soft`, `text-ink-mute`, `text-paper`, etc. Never write raw hex in components. Theme helpers in `app/lib/theme.ts`, toggle in `app/components/ThemeToggle.tsx`. See `docs/light-mode-checklist.md`.
- Security headers are in `next.config.js` (nosniff, frame deny, referrer policy, permissions policy, HSTS one year, a limited CSP).
- React Strict Mode is off (`reactStrictMode: false`) because the animation components do not start under dev double mounting.

## 6. Contact form and email (`docs/emailjs/`, `docs/security-and-abuse-notes.md`)

- Browser posts to `/api/enquiry`, which sends two emails with the EmailJS REST API: an admin email to the owner and an auto-reply (recipient only, no visitor text).
- Private env vars (no `NEXT_PUBLIC_`), names in `.env.example`: `EMAILJS_SERVICE_ID`, `EMAILJS_PUBLIC_KEY`, `EMAILJS_PRIVATE_KEY`, `EMAILJS_ADMIN_TEMPLATE_ID`, `EMAILJS_USER_TEMPLATE_ID`, optional `ALLOWED_HOSTS`. The owner pastes values into Vercel; never ask for them.
- The route checks origin, size and fields, and limits 5 enquiries per IP per hour and 150 per day per server instance. A CAPTCHA (for example Cloudflare Turnstile) is the next step if spam appears.
- Owner must: allow non-browser API calls in EmailJS Security, set the five variables in Vercel, put the inbox address in the admin template's To Email, paste the templates from `docs/emailjs/`, then delete the old `NEXT_PUBLIC_EMAILJS_*` variables. `@emailjs/browser` is no longer imported and can be removed from `package.json`.
